# Brag plan: Maison Regulus (60 s)

Angle: show what the house actually makes. A real portfolio it built (niriantsoa.me), then a storefront site built step by step following the house's four commitments, then the visitor writes in. Every client site is a new star in the house's constellation.

Tone: `polished`, cinematic opening. 1920×1080, 30 fps.
